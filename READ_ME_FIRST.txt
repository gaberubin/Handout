HOW TO APPLY (2 minutes)
========================

This folder contains ONLY the redesigned files, in the same layout
as your project. You are going to overwrite the old ones.

1. Unzip this download.

2. Open the unzipped folder. You'll see:
      app/
      components/
      styles/
      tailwind.config.ts

3. Select ALL FOUR of those items and COPY them (Ctrl+C).

4. Open your project folder  handout-final  (the one that contains
   package.json). PASTE (Ctrl+V).

5. Windows/Mac will ask about conflicts:
      -> choose  "Replace the files in the destination"  /  "Merge + Replace"
   Say yes to ALL.

6. If your dev server (npm run dev) is running, it reloads by itself.
   If not, start it. Then in the browser press  Ctrl+Shift+R  (hard refresh).

You should immediately see: light mint background, green buttons,
new dashboard with green banner + stat cards, new roommate/food/
service cards, new pricing page.

If it STILL looks dark/cyan after this, the paste went to the wrong
folder — make sure you pasted into the folder that contains
package.json, next.config.js, etc.
